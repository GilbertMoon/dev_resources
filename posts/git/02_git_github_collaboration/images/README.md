# Diagram Images

이 폴더의 PNG 파일은 `scripts/generate_git_diagrams.py`와 GitHub Actions로 자동 생성합니다.

## 이미지 목록

1. `01-git-storage-flow.png` — Working Directory → Staging Area → Local Repository → GitHub
2. `02-change-location-by-stage.png` — 수정/add/commit/push 단계별 변경 위치
3. `03-git-vs-github-clone.png` — Git vs GitHub, clone의 의미
4. `04-branch-and-head.png` — Branch와 HEAD
5. `05-team-configuration-flow.png` — 팀 프로젝트 전체 형상관리 흐름
6. `06-project-start-scenario.png` — Clone/Issue/Pull/Branch 시작 시나리오
7. `07-work-branch-commit.png` — 작업 Branch에서 수정/add/commit
8. `08-push-pr-review.png` — Push/PR/Review/수정 반영
9. `09-merge-pull-origin-main.png` — Merge/Pull/main/origin-main
10. `10-merge-conflict-team-work.png` — Merge Conflict와 팀 동시 작업

네이버 블로그에서는 PNG 파일을 내려받아 해당 본문 위치에 첨부합니다.
